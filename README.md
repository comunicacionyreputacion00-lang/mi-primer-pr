# mi-primer-pr

Repositorio de práctica para aprender a crear Pull Requests en GitHub.

## Qué es este proyecto

Este repo se usa únicamente para practicar el flujo de trabajo de Git y GitHub:
crear una rama, hacer un cambio pequeño, y abrir un Pull Request.

## Cómo contribuir

1. Crea una rama nueva.
2. Haz tu cambio.
3. Abre un Pull Request describiendo qué cambiaste y por qué.
